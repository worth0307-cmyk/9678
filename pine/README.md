# Lorentzian Classification 复刻版（Pine v6）

按 *Lorentzian Classification Premium* 说明文档复刻其核心算法，并把校准面板换成
一组能判断真假的指标。文件：`lorentzian_classification.pine`。

## 算法是什么

把若干技术指标归一化成特征坐标，在历史上找 k 个"最像现在"的 bar，每个邻居按
**它之后 N 根 bar 往哪走**投票，票数求和得到 −k..+k 的预测分。

距离用的是 Lorentzian 度量：

```
d = Σᵢ log(1 + |fᵢ(现在) − fᵢ(历史)|)
```

那个 `log` 是它和欧氏/曼哈顿距离的全部区别 —— **它压缩大偏差**，所以某一维差得
离谱、其余维接近的 bar 仍然可能被算作近邻。文档里那张"十字形邻域"的图画的就是
这件事。好处是剧烈行情里不会因为单维爆表就丢掉整个样本；坏处是"相似"的定义被
稀释了，维度越高越明显。

## 实现了什么

| 部分 | 说明 |
|---|---|
| 特征 | 5 个内置（RSI/WT/CCI/ADX 任选）+ 5 个 `input.source` 自定义源，可选自动归一化 |
| k-NN | Lorentzian 距离，时间降采样（`i % 4`），近似近邻扫描 |
| 过滤器 | 波动率、KLMF 趋势状态、ADX、EMA/SMA、日线核方向 |
| 核回归 | Nadaraya-Watson 有理二次核 + 高斯核滞后线 |
| 包络 | 核回归线 ± ATR 近/远带，用于分级均值回归信号 |
| 信号 | 主箭头、首次回调三角、普通/强均值回归标记 |
| 数值流 | −6..+6，`display.data_window`，给外部回测框架用 |
| 校准面板 | 见下 |
| 警报 | 8 种 |

## 面板为什么重做

Premium 宣传图上是 **Win Rate 92.9%、Profit Factor 49.4**，而同一张表里
**Sharpe 0.29、Sortino 0.589**。

这三个数不相容：92.9% 胜率配 W/L 0.93 推出的盈利因子约 12，不是 49.4。而真正该
信的是 Sharpe —— **高胜率 + 低 Sharpe 的唯一解释是赢得少、输得多**。42 笔样本
连统计意义都谈不上。面板自己也印着 "Not a substitute for proper backtesting"。

根本问题是：**胜率首先是止盈止损结构的性质，其次才是策略的性质**。任何 1:3 的
括号在随机游走上都约 25% 胜率，任何 3:1 的都约 75%，和信号好坏无关。

所以这个版本报的是：

| 列 | 为什么是它 |
|---|---|
| **期望值(R)** | 每笔平均赚多少个 ATR。**唯一直接决定盈亏的数。** |
| 盈亏比 | 和胜率共同决定期望值；单看胜率没有任何意义 |
| **基准胜率** | 同期"闭眼按同方向持有同样根数"的胜率 |
| **超额** | 信号胜率 − 基准胜率。**这一列接近 0 就说明信号没提供信息**，哪怕胜率写着 90% |
| 提示 | 笔数不足 / 超额≈0 / 高胜率低期望 / 期望为负，自动标出来 |

多空分开统计再加权，因为做多的基准是"同期上涨比例"、做空的基准是"下跌比例"，
混在一起算会互相抵消，最后得到的"超额"恒等于 `胜率 − 50%`，那是个假指标。

## 三个坑，都标在代码里

**1. 标签对齐（第 3 节）** — 这是唯一一处对错会颠覆结论的地方。

在 bar *t* 算出的 `sign(close[t] − close[t−N])`，既是 *t* 的"过去 N 根"，
也是 *t−N* 的"未来 N 根"。**前向模式**读 `yArr[i+N]`，学的是"特征长这样时，
之后会怎样"；**后向模式**读 `yArr[i]`，学的是"特征长这样时，刚才那段是涨的"。

两者只差一个偏移量，但一个是预测、一个是描述。做成了开关（默认前向），
是为了让你能亲眼比一遍。**如果你去读任何流传的开源实现，这一行值得自己核对。**

前向模式的代价是最近 N 根 bar 的标签还不存在，必须排除在训练集外 —— 代码里
扫描范围因此停在 `bar_index − N`。

**2. 近邻扫描不是教科书 k-NN（第 4 节）** — 它只看 `i % 4 == 0` 的 bar，且只在
`d >= lastDistance` 时收下候选，然后把门槛提到已收集距离的 75% 分位。结果是它
**不保证**取到真正最近的 k 个，而是一个偏向"距离较大但分散"的采样器。这不一定
更差（降采样确实能避免邻居全挤在同一段行情里），但它没有 k-NN 的理论保证，
写成 k-NN 会让人高估它。

**3. 面板没扣成本** — 原版也没有。币安 U 本位永续普通用户**吃单 5bp/边**，
一来一回 10bp；持仓过结算点还要付资金费率（本仓库实测六个主流币的多空组合
净支出约 1.2%/年）。短周期信号非常容易在毛收益为正的情况下净亏。

还有一点：**走式归一化**（`normalize`）只用已发生的极值，所以不偷看未来，但
同一根 bar 的特征值会随着后来出现新极值而改变含义 —— 这在任何基于历史相似度的
方法里都是一层看不见的漂移。

## 实测：这个算法在真实数据上是什么表现

`scripts/48_lorentzian.py` 把同一套 k-NN 搬到六个币（BTC/ETH/SOL/BNB/TAO/HYPE）、
2022-01-01 起的日线上，按币安真实费率（挂单 2bp / 吃单 5bp）和**真实资金费率**
结算，并和等权买入持有并排比。

**按设计跑（前向标签）：没有边际。**

| 成本档 | 毛收益 | 资金费率 | 手续费+滑点 | 净收益 | Sharpe | 买入持有 |
|---|---|---|---|---|---|---|
| 挂单 2bp + 0bp | −6.8% | +0.4% | −2.6% | −9.0% | −0.20 | **+35.1%** |
| 吃单 5bp + 1.5bp | −6.8% | +0.4% | −8.4% | −14.8% | −0.34 | +35.1% |

**毛收益就已经是负的**——不是被成本吃掉的。最干净的证据是命中率：

| 币 | 命中率 | 方向匹配的基准 | 超额 |
|---|---|---|---|
| BTC | 50.47% | 50.53% | −0.05% |
| ETH | 50.38% | 50.06% | +0.32% |
| SOL | 51.43% | 51.44% | −0.01% |
| BNB | 46.07% | 47.33% | −1.26% |
| TAO | 45.96% | 45.96% | +0.00% |
| HYPE | 48.47% | 50.29% | −1.82% |

平均超额 **−0.47%**。邻居投票对"接下来会怎样"不携带信息。4×4 参数网格
（k ∈ {4,8,16,24} × N ∈ {2,4,8,16}）**16 格全为负**，中位 −0.92 —— 不是挑错格子。

**两个附带结论：**

1. **原版那个"不是 k-NN"的扫描是承重的。** 采样器 −0.34，换成真·k-NN
   **−0.75**（年换手从 130x 飙到 330x）。而且两者的**同号率只有 42.2%**，
   低于 50%——它们给出的方向多数时候相反。那不是"近似"，是两个算法。
2. **后向标签版反过来做有东西，但证不出来。** 后向版 −0.59，反向 +0.44 净
   Sharpe（剔 beta 后 +0.51，alpha +26.4%/年，与买入持有相关 −0.11）；朴素均值
   回归（−sign 2/4/8 日涨跌）三档全亏，所以它不只是"最近涨跌"的代理。但反向
   是**被结果诱导出来的**，一路试过约 30 组，去偏 Sharpe 在 30 组下
   P(真实>0) = **0.13**，且收益高度集中在 2023（+1.59），五年里两年为负。

## 用法

1. TradingView → Pine 编辑器 → 新建指标 → 粘贴 `lorentzian_classification.pine` → 保存 → 添加到图表
2. 先用默认设置看行为，**特征数从 3~5 开始**（维度越高近邻越稀疏）
3. 自定义源要先把那个指标加到图表上，才会出现在下拉框里
4. 看面板的**超额**和**期望值(R)**，不要看胜率
5. 看**两法同号率**那一行：低于 50% 就说明"换个选法结论就反过来"
6. 笔数 < 30 的时候面板上的所有数字都不要当真

## 没做验证的部分

**我没有 Pine 编译器**，这份代码是静态审查过的（语法、声明顺序、函数定义、
Pine 不允许对函数调用结果取历史值等），但**没有在 TradingView 上编译运行过**。
首次粘贴如果报错，把错误行发我。

更重要的是：**算法本身有没有边际，这份 Pine 回答不了**。它只能告诉你在某一段
图上、某一组参数下发生了什么 —— 而文档里那张超参数重要性图说明作者做过
数千组参数的网格搜索，那是极大的多重检验暴露。本仓库的 `41`、`45`、`46`
号脚本量化过这类搜索该打多少折。
