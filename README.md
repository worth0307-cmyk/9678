## 目前最有希望的方向：横截面

所有时序信号都在和"币圈 beta"搏斗（六币第一主成分占 73% 方差）。
横截面多空组合从构造上把它减掉，只赌"谁比谁强"。

| | 值 |
|---|---|
| VI(16) 价差横截面排序，多空各 2 | **Sharpe +1.48**，收益 +222.2%，回撤 −21.8% |
| 对币圈 beta 的暴露 / 年化 alpha | **−0.02** / **+36.3%** |
| Deflated Sharpe（31 配置） | **52.7%**（全研究最高，此前 25.7%） |

| 分年度 / 滚动 180 天 | 2023-2026 **全部为正** / 80% 窗口为正 |
| **26 币复测后** | **剔除 TAO+HYPE 只从 +0.94 掉到 +0.89**（6 币时是崩到 −0.07）——对单一名字的依赖消失 |
| 最优构型（26 币） | 动量14d 多空各 5 只、每 3 天再平衡：**Sharpe +1.13** [CI +0.28,+1.96]，beta −0.02，alpha +38%，回撤 −28.8%，四年全正 |
| 仍未解决 | deflated Sharpe **32.7%**；前 3 名占 56% 收益；仅用 20 个新币时弱到 +0.44 |

机制是**离散度**：4 主流币每日横截面标准差 0.956%，加上 TAO/HYPE 翻倍到 1.848%。
月度验证 corr(离散度, 收益) = +0.247，高离散月 +1.98% vs 低离散月 +0.92%。

**这不是伪装的做空 TAO**：全程做空 TAO 是 Sharpe −0.06 / −77.1%（波动拖累），
而策略在 TAO 上做多贡献 +43.5%、做空贡献 +19.1%，两边都赚。

> ## ⚠️ 2026-09 对横截面动量的两项修正（`REPORT_RESMOM.md`、`REPORT_PCA.md`）
>
> **① 「动量其实是 beta 轮动」这个怀疑被否掉了。** 直接量每天的 Σ(权重 × PC1 载荷)：
> 敞口均值 +0.001、标准差 0.004，与次日大盘涨跌的相关性 ≈ 0。
> rank 加权 + 美元中性的构造**本来就是因子中性的**，剥主成分没有任何增量。
>
> **② 但排序变量该改：波动归一化值 +0.68 Sharpe（样本外）。**
> 181 个从未参与开发的币、$10M 门槛：raw 14 天动量 **−0.63**，
> 换成 14 天波动归一化动量 **+0.05**。这是本项目在这条策略上最大的单项改进。
> 流动性方向同样强且单调：门槛提到 $100M，raw 从 −0.63 变成 +0.47。
>
> **但样本外在预注册的 $10M 门槛下仍然只有 +0.05**（bootstrap [−0.86, +0.96]），
> 样本内是 +1.41。流动性只解释了约三分之一的衰减。**这套策略还不能算验证过。**
>
> 顺带修了一个真 bug：`xsec.run` 报的年换手对组合回测一直是从**总敞口**算的，
> 美元中性组合的总敞口恒为 1.0，所以永远报接近 0。成本计算一直是对的，只有诊断值错。

> ## 六均线「双均线交易系统」（`REPORT_MA.md`）
>
> MA20/60/120 + EMA20/60/120，均线密集/发散，两条开仓法。视频给的画像是
> 「胜率 30~40%、赔率至少 1:3」——**复现出来完全对得上（样本外 181 币日线：
> 胜率 31.5%、赔率 1:2.5）。但这是 1:3 括号的几何性质，不是策略的性质**：
> 随机入场配同样的括号，画像一模一样。
>
> 把「均线密集」这层拆掉：**不要求先有密集的随机突破反而更好**
> （+0.195R vs +0.096R，p=0.989），密集这个前提在开仓法 A 上是负贡献。
> 只有「密集→发散后第一次回踩 MA20」赢了随机入场，但很薄，且按视频自己的
> 1% 仓位规则，**一个币一年 1.5 个信号、年化 +0.23%**。
> 斐波那契平仓法在快周期上去掉最好 1% 的交易就翻负。

> ## ⚠️ 2026-08 样本外检验修正了主结论（`REPORT_OOS.md`）
>
> 在 181 个从没参与开发的币上原样跑这套策略：**Sharpe −0.68、总收益 −80.1%**。
> 零成本下仍是 −0.52，所以不是成本问题；按比例放宽选择度更差（−1.06），所以不是选得太极端。
> **原因是流动性**：开发集日均成交额中位 $60M，样本外只有 $4M。
>

> 在 $30M/$50M 上稳定。**所以下面那个 +1.13 高估了大约一倍，真实预期约 +0.5 / CAGR 约 12%，

## 先过这一关：边际算术（`scripts/41_edge_arithmetic.py`）

评估任何新想法之前先跑一遍，避免把时间花在算术上就不成立的东西上：

```bash
python scripts/41_edge_arithmetic.py                      # 完整表格 + 自检
python scripts/41_edge_arithmetic.py --win 0.51 --payoff 1
python scripts/41_edge_arithmetic.py --gross 0.096 --turnover 441
```

三条结论（全部可由 `vibt/edge.py` 的闭式解得到，有测试卡着）：

1. **胜率单独没有意义。** 51% 配 1:0.8 是 −0.082R，45% 配 1:3 是 +0.800R。
2. **最优止损 `s* = 4c/e`，且在那里净期望恒为毛期望的一半**——无论边际多大，
   一半交给交易所，没有更省的配置。
3. **可达 Sharpe ∝ e²**。51%/1:1 在 6.5bp 下最大 Sharpe 只有 **0.05**，
   55% 是 **1.32**。从 51% 到 55% 不是「好一点」，是「从不存在到能做」。
   而 51% 需要约 **1.5 万笔**才能和抛硬币区分开——一年 250 笔要 62 年。

再平衡型策略走另一支：`打平成本 = 毛年化 / 年换手`，直接和手续费比。

## 关于 VI-Dashboard 通道打法的结论

1. **下轨从不触发，而这恰恰在帮你。** 1D 下轨 0.60 落在 VI+ 的 **0.7 分位**，两年半只触发 2 次。改成滚动自适应通道后下破触发 51 次，做多那半边活了过来——**然后 2026 年从 +7.2% 变成 −12.9%**。它靠着不触发替你挡掉了一条亏钱的多头。
2. **做空上破亏钱，这条被六币种坐实了。** BTC 单币 3.6 年：73 笔空单均值 −0.62%，**t=−2.36**，P(均值>0)=0.4%。六币池化 359 个事件，三种通道口径下 P(均值>0) 分别为 0.9% / 0.3% / 4.4%。
2b. **但"信号有预测力"我之前说过头了（已订正）。** 扣掉这段时间币圈本身的漂移后（随机开仓 48h 也有 +0.28%），超额只剩 +0.37%~+0.59%，**p=0.07~0.19，均不显著**。你亏钱主要不是信号在骗你，而是**在一个整体上涨的资产类别上做空**。
3. **但它在熊市里是对的**：事件后 2 天，2024 牛市 +2.05%(t=3.0)，2026 熊市 −1.34%(t=−2.1)。VI+ 是动量延续检测器，盈亏符号跟着大趋势走。
4. **逐笔胜率 53%、中位数 +0.04%，但均值 −0.59%** —— 平均亏损是平均盈利的 3.2 倍，最差一笔 −12.19%。用起来"感觉挺准"，死在尾部。
5. **加仓是最大的漏洞**：去掉加仓，亏损从 −30.1% 收窄到 −15.2%。VI+ 继续外扩 = 空单正在扩大亏损，此时加仓等于最糟时刻加倍下注。
6. **VI+ 的高低两端都是"动量延续"，不是"超买超卖"。** VI+ 高→继续涨，VI+ 低→继续跌（滚动通道下破后 +48h 为 −0.88%，n=51）。两边逆着做都是错的。
7. bootstrap：P(真实单笔均值 > 0) = **1.4%**。这是整份研究里唯一统计上站得住的结论。

8. **VI+ 真正测量的是波动，不是方向。** 事件后高低跨度是随机日期的 **1.10~1.30x（p<0.01）**，但 **|净收益| 只有 1.01x（不显著）**——价格走的路更长，终点却没更远。控制了波动率聚集（事后ATR÷事前ATR）后依然显著。
9. **但这个发现赚不到钱。** 拿它去给日线系统减仓，六币等权组合 Sharpe 在 x1/x0.9/x0.8/x0.5/x0 下全是 0.99，与基准差异 t=−0.6。效应量太小，且日线系统本就在做波动率标定。
10. **六个币其实只值 1.4 个币。** 平均两两相关 0.673，第一主成分占 73% 方差，有效独立标的数 = 1.37。事件还在时间上聚集（359 个事件只落在 93 个周）。按周聚类重做 bootstrap，做空上破的 P(均值>0) 从 0.3~0.9% 放宽到 **1.7~2.8%**——结论仍成立，但以聚类值为准。

详见 [REPORT_VI_BAND.md](REPORT_VI_BAND.md)。

## 三句话结论（另一条线：从零构建的日线系统）

1. **1 小时级别做不了。** 测过的每一个 1H 变体全部亏损（最差 −95.6%）——不是指标问题，是 13bp 往返成本占了 1H 中位振幅的 11%。
2. **单参数回测全是幻觉。** 日线 VI 仅多组合样本内平均 Sharpe +1.09，样本外 −0.74；而 VI(14) 那个漂亮的 1.06 是一根孤立尖刺，n=16 就掉到 0.25。
3. **真正稳的是"降暴露"。** 样本外那波 −50% 熊市里，所有家族、所有参数、100% 的格子都跑赢了拿现货。这不是 alpha，但它可复制。

## 核心设计

```
目标仓位 = clip(看多票比 × 40% / 已实现波动率, 0, 1) − 确认空头 × 25% × 同一标定
```

- **12 票**：Vortex 和 DMI 各取 6 个 lookback（10/14/20/28/36/48）
- **只用高低点**：VI 和 DMI 由区间关系构成，日线上稳定优于收盘价均线（家族中位 Sharpe 0.49/0.64 vs EMA 0.20）
- **Parkinson 波动率**做仓位标定，比收盘价估计效率高约 5 倍
- **空头是保险不是 alpha**：整体拉低 Sharpe，但把熊市亏损从 −15.4% 收窄到 −11.5%
- **仓位按 20% 网格取整**，避免噪声换手。年换手 24.7 倍，年化成本拖累 1.60%
